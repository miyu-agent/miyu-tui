## 终端无缝集成（shellhook）

状态：施工中。设计 `22-命令行.md` 第七节、O6（核心仓库；2026-10-20 项目主人定：叫 shellhook，并进终端界面这个包，程序就是 `miyu-tui`）。时间线、主题、抽屉的样子照 `tui.md`，这一页只写 shellhook 自己的；共用的写「照 `tui.md` 某节」，不抄一份。

### 是什么

在 shell 里直接和她说话：提示符上敲一句话回车，她的回答照终端界面时间线的样子印在 shell 里（不全屏、不能点开）。核心把 `miyu shellhook …` 转交成 `miyu-tui shellhook …`（清单里第二个 `[[command]]`，核心 F-13）。

### 命令

| 命令 | 谁用 | 做什么 |
|---|---|---|
| `install [--shell <名字>] [--program <路径>]` | 人 | 装进 shell。`--shell` 没给的照上一层进程认（Linux 读 `/proc/<ppid>/comm`），再照 `SHELL`；Windows 上照 `PSModulePath` 里 PowerShell 自己加的用户模块目录认 5.1、7（系统目录 cmd 里也有，不算）；认不出的说一声、退出码 1 |
| `uninstall [--shell <名字>]` | 人 | 删掉 |
| `status` | 人 | 三种 shell 各一行：装没装、装在哪；记的程序不在了的说要重装；旧版那一份也在的说一声 |
| `script --shell <名字> --program <路径>` | 装进去的那一行 | 印这种 shell 的脚本 |
| `classify --shell <名字>` | 脚本 | 标准输入是多行的一段：是命令退出码 0，是话 1 |
| `follow --watch <路径>` | `say` 起的 | 盯后台（下面「后台回报」） |
| `report --shell-pid <编号> [--leftover <路径>]` | 脚本 | 印这个 shell 信箱里的后台回报 |
| `say --shell <名字> [--shell-pid <编号>] [--leftover <路径>]` | 脚本 | 标准输入是那句话：交给她、这一轮印在 shell 里（下面「say」）。退出码：正常 0，按了 Ctrl+C 3（同 `miyu ask`），连不上核心 1 |

终端界面的第一次引导不走命令行，直接调 `shellhook::setup`（2026-10-23 项目主人要引导里加一步「是否无缝集成至终端」）：`shells()` 列这台机器上有的 shell（PATH 上找得到的、找不到却装过的）和装没装，`install(名字)`、`uninstall(名字)` 照 `install`、`uninstall` 那一套装、删，不往标准输出印，失败交回给人看的一句。

1. 帮助（`-h`）只列给人用的三个。用法写错了退出码 2，别的出错 1，同核心命令行（设计 22 O1）。
2. `--program`：脚本调哪个程序，没给的照这个程序旁边的 `miyu`（随 Miyu 装的界面放在它旁边，设计 32 第六节），没有的调自己。不按名字去 PATH 里找：并行期 PATH 上的 `miyu` 是旧版（设计 27）。临时部署用包装脚本的，装的时候写 `--program <包装脚本>`。

### 装在哪、装进去什么

1. fish：`$XDG_CONFIG_HOME/fish/conf.d/miyu-shellhook.fish`（没设的 `~/.config`），整个文件是自己的；bash：`~/.bashrc`；zsh：`$ZDOTDIR/.zshrc`（没设的 `~`），启动文件里一段，前后带记号（`# >>> miyu shellhook >>>`、`# <<< miyu shellhook <<<`）。
2. 装进去的只有一行：交互的 shell、程序在，就跑 `<程序> shellhook script --shell <名字> --program <程序> | source`（bash、zsh 是 `eval`）。脚本每次 shell 起来时现印，升级以后自动是新的，不另外提供 `init`（2026-10-20 项目主人定）。
3. 不动不是自己写的：fish 的那个文件第一行不是记号的，装、删都不动它，装的说一声、退出码 1。启动文件里只换、只删记号中间那一段，别的原样。
4. 再装一次换掉原来那一段，不加第二段；回「已更新」。
5. 顺着符号链接写到它指的文件，链接还是链接；先写在旁边再换过去，权限照原来的。
6. 旧版那一份（fish 的 `conf.d/miyu.fish`）也在的，装完、`status` 时说一声：两份都接管回车，一句话会交两遍。不删它。

### shell 的脚本（fish、zsh、bash）

底子是旧版的 fish 配置（设计 22 第七节），只换了调的程序：

1. 回车：空行照常；单行的看没展开的首词（`--tokens-raw`），是普通词又不是任何命令的交给她，别的交回 fish；多行的先看首个命令在不在，不在的问 `classify`。
2. 交给她：记进 fish 的历史，清空输入行，在提示符那一行照普通的字色重放这句话（2026-10-23 项目主人：「让文字别回车后全部变成红色了」，原来照报错色，四种 shell 一起改）；清空和重放包在一段同步输出里，不闪（旧版 2026-10-01 报过）。
3. Ctrl+J 换行。找不到命令时兜底交给她（`fish_command_not_found`）。
4. zsh（2026-10-22）：回车换成自己的小部件（`zle -N accept-line`），判法同 fish：单行看首词（`${(z)…}`，跳过 `变量=值`）是普通词又 `whence` 认不出的是话（单独一个 `-` 不算命令：zsh 当它是前缀修饰，2026-10-22 验收「- 说的……」这种多行话被当成脚本一行行跑了；多行的 `time`、`test`、`date`、`which`、`type`、`command`、`history` 也交给程序判，同 fish），多行的先看首个命令、再问 `classify`。交给她就在小部件里（`zle -I` 以后程序自己用终端，同 fzf）：这一行留在屏幕上照普通的字色（`region_highlight` 写 `fg=default`，语法高亮插件标的也盖掉），记进历史（`print -s`），答完提前敲的字放回命令行。答话时来的后台回报记着、答完印（`TRAPUSR1` 看 `__miyu_busy`）。`Ctrl+V` 绑同一个 `paste`，`Ctrl+J` 在命令行里换行（同 fish）。`/edit` 的 `.redo` 标记同 fish，开新的一行（`zle-line-init`：`Ctrl+C`、执行了别的命令）就不算在编辑。
5. bash（同一天）：readline 一个键里没法先判再决定执不执行，回车绑成两个键的宏 `\C-x\C-a\C-x\C-b`：第一个 `bind -x` 跑判断（同 zsh，认命令用 `type -t`），是话就当场交给她，再把第二个键（`accept-line`）换成空的，这一下不执行；是命令的换回 `accept-line`。bash 跑 `bind -x` 以前擦掉输入的那一行（只擦提示符最后一行），照 `${PS1@P}` 的最后一行加普通的字色重画；答完 bash 只重画提示符最后一行，前面几行先补上（实测 bash 5.3）。提前敲的字放回 `READLINE_LINE`。`Ctrl+V` 绑 `bind -x`，绑以前关掉 `bind-tty-special-chars`（readline 每读一行都把 stty 的 lnext `^V` 绑回 quoted-insert，盖掉自己绑的，同一天验收）；`Ctrl+J` 换行；`/edit` 的在编辑记号在 `PROMPT_COMMAND` 里清（`Ctrl+C`、执行了别的命令都会画新的提示符）。emacs、vi 插入、vi 命令三套键表都绑回车（命令模式里回车也判）。
6. 两边都留着找不到命令时交给她（`command_not_found_handle`、`command_not_found_handler`）兜底。
7. PowerShell（2026-10-23 项目主人：「powershell 的集成可以做一下」）：`pwsh`（7，各平台）和 Windows 自带的 `powershell`（5.1）两种，脚本同一份（`hook.ps1`），要 PSReadLine（5.1 自带 2.0），没有的不接管。启动文件问 PowerShell 自己的 `$PROFILE.CurrentUserCurrentHost`（「文档」可能被挪到 OneDrive，自己拼会错），一段带记号，同 bash；新建的带 BOM、说明只写 ASCII（5.1 照系统代码页读没有 BOM 的文件）；程序印的脚本照 UTF-8 读进来再 `Invoke-Expression`。回车用 `Set-PSReadLineKeyHandler` 接管：照 PowerShell 自己的词法（`Parser::ParseInput`），头一个词（跳过注释、换行）是当命令名用的裸词、`Get-Command` 认不出的是话；变量、表达式、关键字、路径、认得出的都照原样执行，多行的同样只看头一个词，不问 `classify`。头上是这个 shell 贴过的块（`[图片 1]`、`[已粘贴 14 行]`，照 `paste` 记在信箱目录里的那一份认，贴的是字的不记）的也是话，同别的 shell：PowerShell 把 `[…]` 当类型字面量，原来判成命令、执行报错（2026-10-26 Windows 虚拟机里实测）。是话的 `RevertLine` 清掉命令行、照普通的字色重画、记进历史，那句话写进临时文件交给 `say --input`（5.1 的管道照 `$OutputEncoding` 编码，默认 ASCII），答完 `InvokePrompt` 在新的一行重画提示符、`Insert` 放回提前敲的字。调程序不用 `&`：按键处理、提示符函数里 `&` 调的程序输出被收进管道，画面不上控制台，它拉起的核心继承了那根管道，PowerShell 一直等（在 Windows 虚拟机里实测卡死），改用 `Process.Start` 直接用这个控制台。`Ctrl+V` 同 fish（读不到剪贴板的照 PowerShell 原来的粘贴），`Alt+V` 绑同一个（Windows Terminal 自己占着 `Ctrl+V`，剪贴板里只有图时什么都不送进来，2026-10-26 虚拟机里实测），`Ctrl+J` 换行（`AddLine`）。没有信号可等：后台回报在画提示符时看一眼信箱（脚本里写着信箱目录），有的印，同 bash 要等下一次画提示符。`/edit` 的在编辑记号在包了一层的 `prompt` 里清。Windows 客户端默认的执行策略 `Restricted` 不加载启动文件：装的时候查，是 `Restricted`、`AllSigned` 的说一声怎么改（`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`），不替人改安全设置。

### say

1. **说到哪个会话**：先问核心 `session.terminal {cwd}`（核心 8-33）：哪个算终端会话、闲置多久换新的都由核心定（设计 22 第七节，2026-10-20 项目主人：头去建会话是向上依赖）。问到的照 `Open` 接上，等最新一页读回来（`Paged`，读不成的 `Older`）再说那句话；问不到的（核心旧）照新会话开。先读完再发：补发的那一页里有同样一句话的时候，不会把以前那一轮认成这一轮（真模型实测撞见）。 **每个终端各一个终端会话**（核心 T-22，2026-10-23 项目主人：「不同终端不同会话，注意，只有真的对话了才开新会话，不是开了终端就开新会话」；原来几个 shell 共用一个，A 正在答时 B 说的话排进 A 那一轮，两边的问答混在一起）：问的时候带这个终端的键（`terminal`，`say/terminal.rs` 的 `key`：shell 的进程号加它起来的时刻，Linux 读 `/proc/<pid>/stat` 第 22 项，别处只照进程号；不是从脚本调的没有键，照账号原来那一个）。说话的问了没有就开；不说话的（斜杠命令、`/tui`、交给核心的斜杠命令、`/redo`）只问不开（`create: false`），这个终端还没说过话的：要会话的命令说一句「这个终端还没和她说过话」不办，列表、配色、帮助、人格、`/new` 照常，`/tui` 起不接会话的全屏。`/new`、`/sessions` 也只动这个终端的指针。核心拒了带键、只问不开的问法（T-22 以前的核心不认）的照原来的问法再问一次。核心还没有机主（核心 Y-12：握手回 `setup: true`，只能注册）的说话、斜杠命令都不办，暗色说一句「还没注册：先运行 miyu 打开全屏界面，在引导里设好用户名和密码」（注册在全屏的引导里做，shell 里不做）；`doctor` 同样说还没注册，不说连不上（2026-10-26 在 Windows 虚拟机里换新核心时撞见）。
2. **在哪个目录说**：每句带 shell 所在的目录（`session.send` 的 `cwd`，核心 05eb8159）；全屏不带。
3. **印哪几条**：只印这句话开的那一轮：发出去以后，核心把这句话落盘推回来记下序号（这条连接自己发的推回来是只带序号的 `user_message`，别处看到的是带字的 `said`，认第一个），`turn.started` 的 `trigger` 是它的那一轮就是；说的时候她正在跑别的一轮（回报叫醒的）的，这句话排着，被那一轮听到了（`model.delta` 的 `seen` 到了它）就算那一轮，不另开（2026-10-20 实测：原来一直等不到自己开的那一轮，终端不回来）；这一轮里有任务表里的任务结束了、她之后的请求没带上的（`model.delta` 的 `seen` 没到那条回报的序号，`unseen.rs`），核心在这一轮结束的同一刻叫醒她再开一轮，`trigger` 是那条回报：照序号认出来接着印、等它结束再还终端，最多等半秒（同一天实测：任务在这一轮里跑完，叫醒的那一轮没人印；还没结束的才交给盯后台的）。任务表里也记补发的那一页里以前派的（`JobEarlier`、补发的 `job.started`）：以前派的在这一轮里结束，绿点照时候印在这一轮里（同一天验收 SH-30：原来落到了最后）；这样印过的从信箱里拿掉，回到提示符不再印一遍；接上时补发的最新一页不印（一件一件来：等到一件以后先把已经到了的都办完再画一帧，不然以前弹过、已经答了的确认框会闪一下，同一天验收）。你说的那句 fish 已经重放过，不印。排法照全屏（`ui/rows.rs` 的 `entry_rows`，一条之间空一行），最前面空一行和提示符那一行隔开，等第一个字时末尾转着。不印运行状态行（词、用时）：shell 里只要转圈（2026-10-20 项目主人验收）。展示的卡片点不开：「点击打开」那一行换成文件的路径（同一天）。图（图片、公式、mermaid）还不显示。
3a. **待办**：发出去以后推来的待办照全屏的任务表记，在活动区末尾照侧边栏的样子画（`ui::todo_lines`）；这一轮变过的，收尾时把最后的样子一起印出来。
4. **换了会话**：回应带 `renewed` 的，这一轮前面先印一行暗色的「上次说话是 3 小时前，开了新会话」（单位取最大的一级：分钟、小时、天）。
5. **配置**：时间线那几项（`tui.timeline_*`）照全屏读、照全屏用，做完收起照 `tui.timeline_fold`。
6. **收工**：这一轮结束（`running` 回到没有）就收；还没开轮就被拒的、连不上的当场收，原因写在标准错误。
7. **按键**：读按键时终端在原始模式。Ctrl+C 打断这一轮（`session.interrupt`，排着的退回来）；还没开轮、已经按过一下的不等了，当场收。别的字记下，收工时写进 `--leftover` 的文件，脚本放回命令行。收工时先让读按键的线程停下，再把它读走还没处理的按键收下（答得快时最后几个字会丢，实测撞见）。

### 怎么印

1. 光标下面一块活动区，每一帧先擦掉上一帧（回到它的第一行、往下全清）再画，包在同步输出里（设计 22 第七节：旧版每帧先擦再写，一闪一闪）。
2. 活动区最多占终端高减一行；长过的只露最新的那一截。这一轮结束时擦掉活动区，整段照最后的样子印一遍，留在滚动区：做完收起的照配置收起。
3. 每一帧先画进一块和终端一样宽的画布，照全屏那一套收拾（宽字后面那格、`theme::paint`、照色深降色 `theme::degrade`），再一行行写成带颜色的字：宽字只写一次，行尾没颜色的空格不写。

### 后台回报

设计 22 第七节「后台任务和回报」（2026-10-20 项目主人定，核心 b3777b13）。

1. **谁盯**：`say` 记下这一轮派出去的后台任务（`job.started`，前台跑的子代理不算）；收工时还有没结束的，写一份交接（终端会话、任务、`$fish_pid`）进信箱目录，起 `miyu-tui shellhook follow`：自己一个进程组、不接终端。
2. **怎么盯**：订阅终端会话（`Open`，补发的那一页不算），只认交接来的任务编号：结束了（`job.reported`、`child.reported`）记一件「结束了」；她没看到的回报（`unseen.rs`：回报的序号，界面推送 `Reported` 带着；之后请求的 `seen` 够着了就是看到了，不叫醒）叫醒她开的那一轮，`trigger` 是这里盯的回报的，记一件「那一轮」（同一天验收 SH-31：原来认「下一个不是你说的话开的」，别的 shell 里说的话推来是 `Foreign`，没认出来，那一轮被当成叫醒的又印一遍）；这一轮里又派出去的接着盯。都结束了、叫醒的那几轮也跑完了，收工。shell 退出了（Linux 上 `pidfd`，等事件不轮询；Windows 上起一个系统自带的 `powershell` 跑 `Wait-Process` 等它，不写 unsafe、不轮询，2026-10-24；macOS 的 kqueue 还没做）当场收工，不再回报。
3. **信箱**：缓存目录 `shellhook/<shell 的编号>.jsonl`，一件一行，追加；`report` 先换名再读，拿的时候追加的留给下一次。记一件给 shell 发 `SIGUSR1`。
4. **fish 那边**：收到信号时停在提示符上的（`status current-command` 是 `fish`）当场印：回到提示符第一行往下清掉，跑 `report`，补「提示符行数 - 1」个换行再 `commandline -f repaint`（fish 照记着的位置往上回这么多行重画，不补会盖掉刚印的，实测）。前台在跑命令的（vim、一行里的几条）、她正在答的（`say`、`report` 跑着时记着 `__miyu_busy`：她答话时来的信号 fish 等答完才办，那时 `current-command` 已经是 `fish`，会当成停在提示符上往上擦掉刚印的收尾行，同一天验收）先记着，回到提示符（`fish_prompt` 事件）再印；印的时候又来的接着印。敲到一半的字 fish 自己留着；印的时候敲的接在后面。
5. **bash、zsh 那边**（2026-10-20 项目主人要）：找不到命令交给她时带 `--shell-pid $$`（bash 的处理函数在子 shell 里，`$$` 照样是那个 bash）。
   - zsh：`TRAPUSR1` 里 `zle` 开着就是停在提示符上：先 `report --pending` 问信箱里有没有要印的，没有就不动；有的 `zle -I`（zsh 把提示符画到印的下面，光标在旧提示符的下一行），`report --above <提示符行数>` 往上擦掉旧提示符在那里印。提示符行数照 `${(%%)PS1}` 拆成数组再数（只有一行时 `${#${(f)…}}` 数的是字数，实测往上擦多了）。前台在跑命令、她正在答的，zsh 等它结束才办信号，那时 `zle` 没开，记着，`precmd` 里印。她答话时提前敲的字 `print -z` 放到下一个提示符的命令行上。
   - bash：停在提示符上等你敲的时候不办信号，等你回车、这一行读完、命令还没跑时才办；前台在跑命令的等它结束才办（实测 bash 5.3）。那时都不在画提示符，信号里直接印：停在提示符上来的回报，要等你下一次回车，印在那条命令前面（同一天验收：原来记着、`PROMPT_COMMAND` 里印，排在你下一句的回答后面）。找不到命令那条路提前敲的字放不回 readline，不收（回车时判的那条路放得回，见「shell 的脚本」里 bash 那一条）。
   - 收尾行和下一个提示符之间空一行：bash、zsh 印完补一个换行（fish 的提示符自带；同一天验收 zsh 贴在一起）。
   - 接上叫醒的那一轮只印那几轮（`view.rs` 的 `Scope::Turns`）：排到一轮不在里面的就停，后面你说话开的那一轮不印（同一天验收 bash 印了两遍）。
6. **印什么**：「结束了」照全屏写那一行（`jobs::announce`，从全屏挪来共用：绿点、红叉）；「那一轮」照 `Open` 接上、补完最新一页后照 `say` 一样画，要确认、要回答的照常弹，画的时候按键归它。

### 粘贴（`Ctrl+V`）

同终端界面「输入框」第 11、12 条（2026-10-20 项目主人要：「和终端里类似即可」）。

1. **读**：fish 的 `Ctrl+V` 跑 `shellhook paste --shell-pid $fish_pid`：照全屏的先后读剪贴板（复制的文件、图、字，`clipboard::{read_files, read_image, read}`；读来的字全是本机现成的文件、目录的也收成块，同一天验收：原来只认复制的文件），收块的规矩和写法用全屏的输入框（`input::InputBox` 的 `paste_files`、`attach`、`paste`，门槛 `layout.json` 的 `paste_fold_*`、块上的字 `paste_label`、`attach.labels`）。块上的字印到标准输出，脚本 `commandline -i` 插进去；读不到剪贴板的照 fish 自己的 `fish_clipboard_paste`。截图暂存在全屏同一处（`tui/pasted/<shell 的编号>/`，shell 不在了，下次起全屏时清掉）。
2. **记**：块的原文、附件记在 `<缓存目录>/shellhook/<shell>-pasted.json`，留到 shell 退出（下一次 `Ctrl+V` 时清掉已经退出的 shell 的那几份）；附件的编号在这个 shell 里一直往下排（同全屏整个会话往下排）。
3. **`/edit` 放回去**：发出去的是展开了的原文，`/edit` 写回命令行以前把这个 shell 贴过的原文换回块上的字（`paste::fold`，长的先换；图、文件块字里本来就是块上的字），回车照样展开（2026-10-22 验收 SH-76）。
4. **说**：`say` 照字里认出的块（从前往后扫，哪个块上的字在这里起头就是它，同一个样子贴过几次的认最近的那次，块的先后不论）换回原文、带上附件（`session.send` 的附件，同全屏），删掉了的块不要。从 fish 的历史里调出来再发照样认得出（2026-10-21 项目主人：「占位块历史应当从历史调出来时还是有正常功能的占位块」）。
5. **判命令还是话**：块带空格，fish 把方括号连同里面的空格算进一个词（实测），首词只看方括号以前的；块打头的是话（同一天实测：原来整句被当成命令，走了找不到命令那条路）。找不到命令那条路也带 `--shell-pid`。
6. zsh、bash 同 fish（2026-10-22）：回车时判，块打头的首词带 `[`，不是命令，是话。

### 斜杠命令

设计 22 第七节「斜杠命令」（2026-10-20 项目主人定）：终端界面的斜杠命令大多照搬，作用在终端会话上。

   - `/model`（`pick/model.rs`）：列表、筛、画法用终端界面的 `model_list`；换终端会话的模型（`session.configure`），也记成新会话的默认（同终端界面）；终端会话的最新一页读回来以后停到正在用的那个上。`/model 名字` 只认写全的名字、引用（不分大小写），没写全的不猜、列几个对得上的（2026-10-21 项目主人：「v4.1 flash 不是能匹配很多东西吗？怎么能知道自己要换的是什么呢？」）。
   - `/theme`（`pick/theme.rs`）：排法用 `ui::themes`；挪到哪种当场换成哪种的样子，`Enter` 写 `tui.theme`（和终端界面共一项），`Esc` 换回。参数认值和照界面语言的名字。
